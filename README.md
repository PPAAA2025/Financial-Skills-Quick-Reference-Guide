# 财务人 SKILL 速查手册

面向财务工作的 AI Skill 分类速查页面，包含场景、用法、提问样例、安装指令、置顶和风险提示。

## 在线访问

GitHub Pages: https://ppaaa2025.github.io/Financial-Skills-Quick-Reference-Guide/

## 本地预览

直接使用浏览器打开 `index.html`。

页面为静态 HTML，无需构建步骤。推送到 `main` 后由 GitHub Actions 发布至 GitHub Pages。

## Skills

`skills/` 目录包含本仓库编写的可导入财务 Agent Skills。每个技能目录均含有独立的 `SKILL.md`，可以通过手册卡片复制安装指令，由 Codex 或 WorkBuddy Agent 按平台流程安装。
