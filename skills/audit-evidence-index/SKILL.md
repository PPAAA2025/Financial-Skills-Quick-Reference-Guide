# Audit Evidence Index

## Workflow

1. Confirm the authorized folder, audit period, request list, naming conventions, and whether file metadata may be read. Do not search outside the provided scope.
2. Build an inventory of files with relative path, filename, type, size, and modified date. Avoid opening content unless required to classify evidence.
3. Map files to audit requests using explicit identifiers and content. Keep uncertain mappings as candidates, not facts.
4. Identify missing requests, duplicate or conflicting versions, unreadable files, period mismatches, and unsigned/unsigned-status evidence where visible.
5. Create an index linking each request to file paths and status. Preserve originals and do not move, rename, upload, or alter evidence unless asked.
6. Separate administrative completeness from audit sufficiency. Never assert that evidence proves an assertion or that an audit procedure is complete.

## Deliverables

- Request-to-file index with relative paths and status.
- Missing/duplicate/conflict list and follow-up questions.
- Scope, assumptions, and files not inspected.

Treat audit files as confidential. Do not include personal or bank identifiers in filenames or summaries unless necessary and authorized.
